# Apuntes de prueba

El subrayador funciona sobre la **vista renderizada** de cualquier visor de
Markdown. Selecciona esta frase manteniendo Ctrl para verlo en acción.

## Una lista

- La fotosíntesis convierte la luz en energía química.
- Las mitocondrias son la central energética de la célula.
- El ADN guarda la información genética.

## Un párrafo con formato

Prueba a subrayar texto que cruce *cursivas*, **negritas** y
[un enlace](https://example.org) para ver que el formato no se rompe.

> Una cita también se puede subrayar sin perder el bloque.

```
el código dentro de bloques nunca se subraya
```
